# منصة الأنشطة الريادية التفاعلية

منصة جاهزة لأي جهة تنظّم معرضًا أو فعالية ريادية. فيها مرحلتان مترابطتان، وكل شيء يُدار من **لوحة التحكم** دون تعديل الكود:

1. **المستثمر الذكي (الفرز):** يدخل الزائر اسمه وبريده وفكرته، فيحاوره مستثمر ذكاء اصطناعي بسؤالين يستهدفان أضعف نقطة، ثم يقيّمه. من يبلغ درجة التأهل يحصل على **تذكرة** للهاكاثون.
2. **الهاكاثون الافتراضي:** تسجيل الفرق بالتذكرة، ورفع العرض الاستثماري والملفات، وتقييم فوري صارم بالذكاء الاصطناعي، ثم تحكيم لجنة، فإعلان الفائزين وإصدار الشهادات.

## الصفحات
| الرابط | لمن | الاستخدام |
|---|---|---|
| `/welcome` | الجميع | صفحة الترحيب: البوابتان، رحلة المشارك، الجدول، الجوائز، الأسئلة الشائعة، الشركاء |
| `/` | الزوار | المستثمر الذكي (الفرز) من الجوال |
| `/hackathon` | الفرق | التسجيل بالتذكرة، التقديم والملفات، النتيجة، الإعلانات، الشهادات |
| `/judges` | المحكّمون | دخول بمفتاح شخصي، المسارات المسندة، تقييم لكل معيار، تعارض المصالح |
| `/admin` | المنظّم | لوحة التحكم الكاملة |
| `/booth` | شاشة الجناح | أوضاع: تناوب، المستثمر، الهاكاثون، لوحة البيانات، عدّ تنازلي، إعلان (`?mode=` للتجاوز) |
| `/dashboard` | شاشة | مؤشرات حيّة ورسوم بيانية وآخر النشاط |
| `/screen` · `/hack-screen` | شاشة | كل نشاط منفردًا مع شريط الإعلانات |
| `/winners` | المسرح | إعلان الفائزين |
| `/report` | المنظّم | التقرير الختامي للطباعة (A4)، و`?booklet=1` لكتيّب المشاريع |
| `/certificate?c=الرمز` | الجميع | الشهادة والتحقق منها (مع رمز QR) |
| `/privacy` | الجميع | سياسة الخصوصية (نصها من لوحة التحكم) |

## ما يُدار من لوحة التحكم
- **نظرة عامة:** الإحصائيات، حالة النظام (البريد، استهلاك الذكاء الاصطناعي اليومي، التقييمات المعلّقة) وإعادة التقييم.
- **الهوية:** اسم الجهة والفعالية والجناح، الشعار، الألوان، المنطقة الزمنية.
- **المستثمر الذكي:** الاسم، درجة التأهل، عدد المحاولات، شخصيات المستثمرين، بنك المشاكل.
- **الهاكاثون:** الاسم والمواعيد، حجم الفريق، المحاولات، المتأهلون، أوزان الذكاء الاصطناعي واللجنة، طريقة التسجيل (تذكرة أو مفتوح)، الملفات، المراجعة الثانية.
- **المسارات والتحديات، ومعايير التقييم** (المجموع 100).
- **التذاكر والدعوات:** رموز دعوة للفرق المرشّحة مسبقًا.
- **المشاركون:** عرض الفرق، رسالة خاصة لفريق، استبعاد واستعادة.
- **المحكّمون:** حساب لكل محكّم بمفتاح شخصي ومسارات مسندة، وإرسال الدعوات بالبريد.
- **الإعلانات:** للجميع أو للمشاركين أو للمحكّمين أو للشاشات، مع خيار إرسالها بالبريد.
- **الشاشات:** وضع شاشة الجناح ومدة التبديل.
- **صفحة الترحيب:** النبذة والجدول والجوائز والأسئلة والشركاء.
- **الخصوصية والحماية:** نص السياسة، التحقق من البريد برمز، حدود الاستخدام.
- **التقارير والنتائج:** نشر النتائج، إشعار المتأهلين، قائمة الشهادات، التقرير والكتيّب.
- **البيانات:** تصدير CSV، حذف البيانات، استعادة القالب.

## محرك التقييم (lib/evaluator.js)
- كل معيار بمستوى 0–5 بأوصاف مثبّتة، ولا يتجاوز المستوى 1 إلا **باقتباس حرفي** من كلام المشارك.
- **سقوف تطبّقها المنصة** لا الذكاء الاصطناعي: بلا عميل محدد لا يتجاوز «العميل» 2، وبلا سعر لا يتجاوز «الربح» 3، ولا درجة كاملة بلا تحقق من السوق، ولا درجة للعرض إن لم يُرفق.
- **مراجعة ثانية مستقلة** في الهاكاثون تخفّض الدرجات المتساهلة ولا ترفعها.
- **الذكاء الاصطناعي يقرأ ملف العرض (PDF) كاملًا.**
- محاولات توجيه التقييم داخل النص تُتجاهل ويُعلَّم المشروع ⚠️ للجنة.
- **الدرجة النهائية** = تقييم الذكاء الاصطناعي × وزنه + متوسط اللجنة × وزنها (40/60 افتراضيًا). تقييمات تعارض المصالح لا تُحتسب.
- بلا ذكاء اصطناعي تظهر الدرجات **وهمية مع تحذير واضح**.

## الإشعارات والبريد
كل رسالة تُدار من لوحة التحكم ← الإشعارات والبريد: تشغيل/إيقاف، نص قابل للتعديل بمتغيرات مثل `{team}` و`{score}`، معاينة، وإرسال تجريبي.

| الرسالة | متى |
|---|---|
| رمز التحقق | بداية عرض الفكرة (إن فُعّل التحقق) |
| التأهل وتذكرة الهاكاثون | عند تجاوز درجة التأهل |
| نتيجة من لم يتأهل | درجته وما ينقصه وأهم ما يحسّنه |
| رمز دعوة | عند توليد دعوات لقائمة مدعوين بالبريد |
| تسجيل الفريق ورمزه | عند التسجيل، للقائد وكل عضو أضاف بريده |
| نتيجة تقييم المشروع | بعد كل تقييم |
| تذكير من لم يقدّم | تلقائيًا بعد مدة من التسجيل |
| تذكير قبل الإقفال | تلقائيًا قبل الإقفال بعدد ساعات تحدده |
| التأهل للتحكيم النهائي | بزر «إشعار المتأهلين» |
| الفوز / النتائج والشهادات | بزر «إرسال النتائج والشهادات»، مع رابط شهادة لكل عضو |
| دعوة المحكّم وتذكيره | بزر في قسم المحكّمين |
| رسائل المنظّم والإعلانات | عند إرسالها |

- **سجل البريد** يبيّن كل رسالة وحالتها (أُرسلت، فشلت وسببها، لم تُرسل).
- **لا تكرار:** التذكيرات والنتائج تصل كل فريق مرة واحدة.
- التذكيرات تعمل تلقائيًا أثناء عمل المنصة، ومرة يوميًا عبر Vercel Cron (`/api/cron`) احتياطًا.

## صفحة الفريق والدخول
- كلمات المرور تُعيّنها الإدارة ولا تُرسل بالبريد: من لوحة التحكم ← المشاركون، إما لكل فريق (كلمة محددة أو مولّدة) أو «توليد كلمات مرور للفرق الجديدة» دفعة واحدة مع تنزيل القائمة.
- يدخل أي عضو ببريده المسجّل وكلمة مرور الفريق من أي جهاز، ويبقى رمز الفريق وسيلة دخول بديلة.
- كلمات المرور مخزّنة مشفّرة (PBKDF2) ولا تُعرض إلا لحظة إنشائها، ويُوقف التخمين بعد 10 محاولات فاشلة في الساعة.

## الاعتمادية
- التقديم يُحفظ **قبل** التقييم. إن تعطّل الذكاء الاصطناعي يبقى معلّقًا، ويُعاد تلقائيًا من صفحة الفريق أو بزر «إعادة التقييم» في لوحة التحكم، ولا تُخصم محاولة.
- حدود لكل جهاز في الساعة، وسقف يومي لاستدعاءات الذكاء الاصطناعي لحماية الميزانية.
- موافقة إلزامية على سياسة الخصوصية، وتحقق اختياري من البريد برمز.

## التشغيل المحلي
```bash
node dev.js
```
- لوحة التحكم: `http://localhost:3000/admin` بالمفتاح `admin`
- لوحة اللجنة: المفتاح `demo`، أو المفتاح الشخصي للمحكّم
- بلا مفاتيح يعمل **وضع التجربة**، والبيانات في الذاكرة.
- لتفعيل الذكاء الاصطناعي: `ANTHROPIC_API_KEY=sk-ant-... node dev.js`

### الأيقونات
المنصة تستخدم أيقونات [Lucide](https://lucide.dev) (ترخيص ISC) من ملف `public/icons.js`، ويُستخدم في الصفحات بالشكل `<i data-icon="trophy"></i>`. لإضافة أيقونات: أضف أسماءها إلى `demo/icons.txt` ثم شغّل `python3 demo/icons.py <مسار node_modules/lucide-static>`.

### نسخة الصفحات المستقلة
`./demo/build.sh` ثم `python3 demo/standalone.py standalone` لبناء كل صفحة كملف HTML واحد يعمل بالفتح المباشر. البيانات في المتصفح، ويلزم أن تُفتح الصفحات في المتصفح نفسه.

## النشر (Vercel + Supabase + Resend)
1. أنشئ مشروعًا في **Supabase** وشغّل `supabase.sql` كاملًا في SQL Editor. ينشئ الجداول وحاوية الملفات `hackathon`.
2. اربط المستودع بـ **Vercel**.
3. أضف متغيرات البيئة:

| المتغير | القيمة |
|---|---|
| `ADMIN_KEY` | كلمة سر لوحة التحكم (إلزامية) |
| `ANTHROPIC_API_KEY` | مفتاح Claude API |
| `ANTHROPIC_MODEL` | اختياري للمحادثة، الافتراضي `claude-sonnet-5-5` |
| `ANTHROPIC_WORKSPACE_ID` | اختياري: فقط إن كان المفتاح غير مرتبط بمساحة عمل (يبدأ بـ `wrkspc_`) |
| `ANTHROPIC_EVAL_MODEL` | اختياري للتقييم، الافتراضي `claude-opus-5-5` |
| `SUPABASE_URL` | رابط المشروع، مثل `https://xxxx.supabase.co` |
| `SUPABASE_SERVICE_KEY` | **المفتاح السري** `sb_secret_...` (أو `service_role` القديم) من Settings ← API Keys. ليس المفتاح العام `sb_publishable_...` |
| `RESEND_API_KEY` | اختياري لإرسال البريد (التذاكر، رموز الفرق، النتائج، الدعوات) |
| `MAIL_FROM` | المرسل، مثل `هاكاثون <noreply@domain.sa>`، والنطاق موثّق في Resend |
| `SITE_URL` | اختياري: رابط الموقع في الرسائل (يُستنتج تلقائيًا إن غاب) |
| `APP_SECRET` | سلسلة عشوائية طويلة لتوقيع رموز التحقق من البريد |
| `CRON_SECRET` | اختياري: يحمي رابط التذكيرات المجدول |

4. ادخل `/admin`: اضبط الهوية والمسارات والمواعيد والمحكّمين، ثم احفظ.
5. افتح `/booth` على شاشة الجناح.

## الحماية
- الأسرار في متغيرات البيئة فقط. مفاتيح المحكّمين لا تصل لمتصفح غيرهم، ومفتاح الإدارة يُحفظ في جلسة المتصفح فقط.
- قاعدة البيانات مقفلة (RLS) ولا يصل إليها إلا الخادم. الملفات في حاوية خاصة بروابط موقّعة مؤقتة.
- كل الإعدادات تُتحقق في الخادم قبل الحفظ.

## قبل يوم الفعالية
- معايرة: جرّب نحو 15 فكرة حقيقية متفاوتة المستوى، وراجع درجة التأهل.
- بروفة كاملة مع الزملاء من جوالات مختلفة: فرز ← تذكرة ← تسجيل ← رفع ← تقييم ← تحكيم ← نتائج ← شهادة.
- ضع حدًا للإنفاق في console.anthropic.com، واضبط السقف اليومي في لوحة التحكم.
- احذف بيانات التجربة من لوحة التحكم ← البيانات.
- جهّز اتصالًا احتياطيًا لشاشة الجناح.
